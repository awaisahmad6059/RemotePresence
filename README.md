# RemotePresence - Android Application

An Android application project built with Kotlin and Firebase. This repository contains the source code for the RemotePresence application.

## Project Overview

RemotePresence is an Android application developed using Kotlin programming language. The project includes Firebase integration for backend services.

## Tech Stack

- **Language:** Kotlin
- **Framework:** Android SDK
- **Backend:** Firebase (Authentication, Firestore, etc.)

## Repository Structure

- **Java/Kotlin Source:** Under `java/` directory
- **Gradle Build Files:** `build.gradle.kts`, `settings.gradle.kts`
- **Firebase Configuration:** `google-services.json` (expected, typically gitignored)

## Getting Started

1. **Prerequisites:**
   - Android Studio installed
   - Firebase project setup
   - `google-services.json` file placed in `app/` directory

2. **Installation:**
   - Clone the repository
   - Open in Android Studio
   - Sync Gradle files
   - Run on emulator or physical device
